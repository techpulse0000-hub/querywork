QUERYWORK - PROJECT NOTES AND HANDOFF
Updated: 10 November 2026

WHAT THE PROJECT IS ABOUT
Querywork evaluates and improves web-search queries against a specific desired
outcome. The user supplies an initial search, the result they actually want,
mandatory evidence requirements, a target score and a search budget.

The application generates query alternatives, searches through Tavily, grades
returned evidence independently, checks each round's outcome, and refines queries
automatically. It preserves the best independently graded query and the complete
trial history. It began as a research tool for Lead Chain, but the core is general.

INTENDED USERS / PERSONAS
- Lead researcher: discover potential organizations to approach, with source links.
- Research operator: compare search strategies against explicit evidence criteria.
- Prompt/eval builder: version prompts and inspect why retrieval succeeds or fails.
These are intended personas; a commercial target market has not been validated.

AGENT PERSONAS AND RESPONSIBILITIES
1. Search strategist: creates concise, evidence-seeking query variants. Learns from
   successful source wording and missing evidence; cannot award its own score.
2. Independent grader: judges supplied evidence against fixed requirements. It
   does not receive generator reasoning, original query wording or previous scores.
3. Outcome reviewer: checks actual returned results after each automatic round,
   including the final round. Findings inform the next batch. Its narrative is
   advisory and cannot overwrite independent grades.

SCORE INTERPRETATION
Each returned result is graded 0-3. Aggregate score = 100 * sum(grades) / 30,
with ten possible result slots. Missing slots and identified duplicates add zero.
Seven grade-3 results can produce 70, but partial results can also total 70.
One source may list many prospects while occupying a single result slot. A higher
score is not proof of buying intent, full coverage, truth, or outreach success.

START / CONFIGURE
Requires Python 3.12+ and Node.js 22+. Run Setup.ps1, then Launch.cmd.
Open http://127.0.0.1:8766/. Demo mode needs no keys.
For live use, enter keys in Environment or copy .env.template to .env locally.
Validate model/provider access. Review account pricing before paid operations.
Port 8765 belongs to a separate application and must not be modified.
